# 5감 동기화 측정 (2026-10-31)

갤럭시 S23 Ultra(SM-S918N) + 갤럭시 워치4(SM-R870)로 10-29에 찍은 폰+워치 녹화 37편(`data/server/sessions/`)을 다시 정렬했다.
워치 시계 → 폰 시계 사상을 세 방법으로 구한다: 서버 경유 시계(폰·워치가 각자 서버와 시각을 주고받음), 음향 비콘(폰 스피커 18~20kHz 처프를 두 마이크가 같이 들음), 진동 펄스(워치 IMU가 잡은 진동 ↔ 폰 마이크에 들린 진동음).

## 고치기 전

| | 결과 |
|---|---|
| 고른 방법 | 서버 경유 시계 30편, 비콘 1편 |
| 비콘 짝 잔차 | 8~63ms (기준 2ms를 넘어 버려짐) |
| 진동 펄스 짝 잔차 | 67~140ms |
| 손목 오차로 적힌 값 | 5.2~5.8ms (판매 기준 10ms 통과) |

## 원인

1. **float32 정밀도.** `find_events`가 찾은 시각(초)을 float32로 돌려줬고, 호출하는 쪽이 이를 폰 시각(~2.5×10¹⁵ns)에 더하면서 268ms 단위로 뭉개졌다. 비콘·진동 펄스 짝이 모두 엉터리였던 이유다. 합성 세션은 폰 시각이 10¹²ns라서 이 버그가 드러나지 않았다.
2. **워치 마이크의 엉뚱한 정점.** 위 문제를 고치자 비콘 짝은 대부분 한 무리(약 −25ms)로 모였지만, 진짜보다 17·50ms 늦거나 100ms 이른 정점이 섞였다. 워치 마이크가 진동 모터 바로 옆이라 모터 소리와 메아리를 비콘으로 잡는다.
3. **스피커 지연.** 비콘 명령에서 실제 소리까지 0.17~0.27초가 걸린다. 찾는 창(±0.25초)이 끝을 놓쳤다.
4. **서버 경유 시계의 치우침.** 비콘과 비교하면 서버 경유 시계가 워치 시각을 **평균 +24.7ms(±3.5) 늦게** 옮긴다(24편). 가는 길·오는 길 지연이 달라 생기는 치우침이라 왕복 잔차에는 드러나지 않는다. 진동 펄스(워치 마이크를 쓰지 않음)는 비콘 쪽과 맞아서(비콘을 고른 24편에서 평균 차 약 +2ms, 편마다 ±15ms 흔들림), 틀린 쪽은 서버 시계로 본다.
5. **짧은 녹화의 기울기.** 1~2분 녹화에서 직선 기울기가 ±200ppm씩 흔들렸다. 같은 기기 쌍의 녹화 26편을 34분에 걸쳐 보면 시계 차이에 추세가 거의 없어서(수 ppm), 실제 드리프트로 볼 수 없다.

## 고친 것

- `find_events`가 파이썬 float(64비트)를 돌려준다.
- 비콘 짝을 두 번 찾는다. 1차는 ±80ms 창에서 찾고, 시계 차이가 가장 많이 모인 무리(±2ms)로 직선을 맞춘다. 2차는 그 직선 ±4ms에서 정점만 다시 고른다. 무리가 안 생기면 비콘을 쓰지 않는다. 폰 쪽 창은 명령 뒤 0~0.6초로 넓혔다.
- 직선 맞추기에 드리프트 사전값(±30ppm)을 넣었다(능선 회귀). 녹화가 길수록 자료가 이긴다. 옛 녹화처럼 소리 시각 기준점이 녹음 처음 하나뿐이면, 소리로 잰 기울기에 마이크 샘플 시계 어긋남이 섞이므로 오프셋만 맞춘다.
- `scripts/sync_bias.py`가 비콘이 잡힌 녹화로 서버 경유 시계의 치우침을 기종 쌍마다 재서 `data/sync_bias.json`에 적는다. 정렬할 때 비콘을 못 잡은 녹화는 이 값을 빼고 쓴다. 표가 없는 기종 쌍은 서버 경유 시계의 기본 오차를 25ms로 적는다(손목 판매 기준 10ms를 넘음).
- 오차 추정을 정직하게 바꿨다.
  - 비콘 기본 오차: 옛 녹화 3.6ms(같은 기기 쌍 녹화끼리 시계 차이가 흔들린 폭), 기준점이 있으면 0.3ms.
  - 촉각: IMU 400Hz 가정 대신 실제 샘플 간격(워치4 100Hz → 10ms/√12).
- 앱(폰 `AudioWav`, 워치 `WristRecorder`)이 녹음 중 1초마다 `AudioTimestamp`(샘플 번호, BOOTTIME)를 `anchors`로 적는다. 서버는 샘플 → 시각을 이 기준점으로 잇는다(`Audio.ns_at`·`sec_at`). 이 기준점은 녹음이 넘쳐 샘플을 잃지 않는다고 가정한다.

## 남은 것

- 10-29 18:44 녹화 5편은 비콘 짝이 한 무리로 모이지 않아 서버 시계를 쓴다(원인 미확인).
- 진동 펄스 짝 잔차는 여전히 70~100ms다. 워치4 IMU(100Hz)로는 170Hz 진동을 볼 수 없어 동기화 신호로는 약하다(촉각용으로는 그대로 쓴다).
- 치우침 표는 S23 Ultra + 워치4 한 쌍뿐이다. 다른 기종은 비콘이 잡힌 녹화가 5편 이상 쌓이면 `scripts/sync_bias.py`로 채운다.
- 영상 ↔ 폰 마이크 고정 지연(`data/device_latency.json`)은 아직 재지 않았다.
- 새 앱(기준점 기록)은 이 맥에 JDK가 없어 컴파일 확인을 못 했다.
