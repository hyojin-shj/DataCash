녹화

줄을 누르면 원본과 얼굴을 바꾼 판매용 영상을 나란히 볼 수 있어요. 원본은 시연 서버에만 남아 있어요.

녹화미션상태보상가상 인물'같은 사람' 기준 넘은 장면처리 시간라벨
관절·검수가리기(SAM) 얼굴 치환라벨(Spark)그 외

이의 신청

'라벨이 틀렸어요'와 반려된 녹화는 더 높은 모델(Muse Spark Open 816B · Fireworks, 없으면 Spark 1.3 최대 추론)로 먼저 다시 봐요. 바로잡은 라벨은 모델 진화의 정답이 돼요. 판단이 안 되면 여기서 결정해 주세요.

모델 진화 — Muse Glimmer

검증된 라벨과 이의 신청에서 바로잡은 라벨로 Meta 오픈 웨이트 Glimmer 를 키워요. 준비되면 Spark 대신 Glimmer 가 라벨을 붙여요(API 비용 0).

실력 (평가용 단계 정확도)

녹화 단위로 떼어 둔 평가용 단계를 맞힌 비율. 회색 선 = 가장 많은 동작만 찍었을 때, 검은 선 = Spark 대신 쓰는 기준.

학습 데이터

처리가 끝날 때마다 자동으로 다시 만들어요. 단계마다 장면 3장 + 질문 → 정답 동작.

라벨 교차 검증 — Spark 1.3 ↔ Spark Open(816B)

같은 녹화를 두 모델이 따로 라벨. '센서로 검증 + 두 모델이 같은 동작'인 단계만 Glimmer 학습 정답이 돼요.

자주 헷갈리는 동작

가장 최근 평가에서 틀린 것 (정답 → Glimmer 답)

주문

계약·결제를 확인한 뒤 승인하면 묶음(LeRobot)이 만들어지고 구매자 화면에 내려받기 주소가 나타나요.

말로 받은 의뢰

채팅 의뢰로 열린 미션이에요. 목표 시간을 채웠거나 계약이 끝나면 닫아 주세요 — 닫으면 앱에서 사라져요.

API 비용

Meta Model API 호출마다 장부에 적어요. 한도를 넘으면 그 단계만 건너뛰어요.
