# DataCash — server and buyer web

Live demo of [DataCash](https://github.com/hyojin-shj/DataCash): the buyer web (catalog, sample 5-sense timeline, LeRobot v3.0 viewer, quality certificates, ask-in-plain-words requests, quotes) and the collection server the Android phone and Galaxy Watch apps upload to.

The bundled recordings are already masked and face-swapped (synthetic people) — no raw video or face data is included.
